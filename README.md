## 📌 Overview

**MerchantMind** is not a passive reporting dashboard or a generic LLM wrapper. It is an **Intelligent Financial Operating System** designed for Indian retail MSMEs.

Small merchants struggle across disconnected tools—Paytm QR standees, bank accounts, customer Khata diaries, and distributor bills. Cash gets trapped in delayed customer credit (Udhaar) and slow-moving shelf stock just as wholesale distributor payments fall due.

MerchantMind continuously monitors business telemetry, identifies impending liquidity shortfalls days before they occur, explains them with transparent mathematical proof, and provides human-in-the-loop, 1-click recovery actions.

---

## 🚀 Key Features

- 🎯 **Continuous Cashflow Radar:** Tracks rolling 14-day liquidity trajectories, operational burn, and runway without manual bookkeeping.
- 🔍 **Zero-Hallucination Evidence Drawer:** 100% transparent audit lineage. Every recommendation links directly to verified source invoices, Khata aging ledgers, and exact formulas.
- 🛡️ **Human-in-the-Loop Action Center:** 2-step confirmation guardrails prevent unintended communications. The merchant always retains complete authority.
- ⚡ **Omnichannel Recovery Execution:** Dispatches polite customer payment reminders with dynamic 1-tap Paytm UPI paylinks and initiates targeted dead stock clearance promotions.
- 📊 **Closed-Loop Outcome Verification:** Measures actual banking settlement webhooks to prove the real financial turnaround.
- 🔄 **Paytm & Ecosystem Telemetry:** Schema-compliant architecture integrating QR/Soundbox audio alerts, EDC POS terminals, and Tally/Khata ledgers.

## 🧠 The Autonomous Intelligence Lifecycle

$$\text{CONNECT} \longrightarrow \text{UNDERSTAND} \longrightarrow \text{MONITOR} \longrightarrow \text{DETECT} \longrightarrow \text{EXPLAIN} \longrightarrow \text{RECOMMEND} \longrightarrow \text{APPROVE} \longrightarrow \text{ACT} \longrightarrow \text{MEASURE}$$

- **Deterministic Core:** Authoritative calculations, liquidity formulas, aging ledgers, and priority ranking.
- **AI Copilot Overlay:** Polite natural-language WhatsApp drafting, multi-lingual explanations (Hindi/English), and conversational merchant queries.

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Run production build
npm run build
